# Eighty Six (86) — Mindustry Mod

A Mindustry Java mod inspired by the **Eighty Six (86)** light novel and anime series by Asato Asato. This mod introduces weapons, turrets, and military hardware from the Republic of San Magnolia and the Giad Empire into Mindustry.

---

## Features

* **Morpho Coilgun (`morpho-coilgun`)**: High-caliber, long-range railgun capable of piercing multiple enemy structures and heavily armored targets. Requires power and coolant to operate effectively.
* **155mm Towed Howitzer (`howitzer-155mm`)**: Long-range indirect artillery piece for heavy ground bombardments using Blast Compound or Pyratite shells.

---

## Installation

### Option 1: Automatic (In-Game)
1. Launch **Mindustry**.
2. Go to **Mods** $\rightarrow$ **Import Mod** $\rightarrow$ **Import Github Repository**.
3. Enter `RUN1-CS/mindustry-eighty-six` and confirm.
